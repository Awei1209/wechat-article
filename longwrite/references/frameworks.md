# 写作框架库（7 套基础骨架）

用于 Step 3 选择文章结构。你也可以扩展到 10-20 套。

## 1) 痛点-方案（Problem → Solution）
- 适合：工具/方法论/效率/产品
- 结构：
  - H2 痛点是什么（用具体场景开场）
  - H2 为什么会这样（机制/误区）
  - H2 解决方案（步骤化）
  - H2 常见坑与反例
  - H2 一句话收尾（带行动号召）

## 2) 清单（Checklist / How-to）
- 适合：教程、可操作干货
- 结构：按步骤/要点编号；每个要点包含“做法 + 原理 + 例子/参数”

## 3) 对比评测（A vs B）
- 适合：两种工具/路线/策略对比
- 结构：
  - H2 先给结论（适用人群分层）
  - H2 维度对比表（成本/效果/风险/学习曲线）
  - H2 场景化建议（3 个典型场景）
  - H2 真实踩坑/用户声音

## 4) 热点解读（News → Insight）
- 适合：热点事件、行业新闻
- 结构：
  - H2 发生了什么（事实 + 时间线）
  - H2 为什么重要（利益相关方）
  - H2 主流观点是什么（引用来源）
  - H2 我的角度（反直觉/第二序思考）
  - H2 未来会怎样（条件式预测）

## 5) 纯观点（Thesis → Arguments）
- 适合：评论、观点文章
- 结构：观点一句话 → 3 个论据 → 1 个反方最强论据 → 反驳/和解 → 收尾

## 6) 故事（Storytelling）
- 适合：人物、个人经历、案例拆解
- 结构：冲突开场 → 关键转折 → 细节锚定（时间/地点/对话）→ 复盘与启示

## 7) 复盘（Review / Postmortem）
- 适合：项目复盘、失败复盘、增长复盘
- 结构：目标 → 过程 → 结果 → 偏差 → 原因 → 下次改法
