# 配图AI提示词模板

默认每篇规划1张封面＋2张正文插图。支持两种交付：用户要封面配图成品时直接制作图片；用户要提示词时仅交付完整提示词。生成图片时读取可用图像生成技能，使用真实可调用工具，不把提示词当成已生成的图片。生成能力不可用时如实说明，并交付提示词，不伪称一键生成已接入。

每张提供可整段复制的完整提示词，不要求用户自行拼接碎片。

不捏造真实新闻现场、具体人物或官方文件；新闻可用明确的示意插画，图片说明注明示意。避免商标、水印、虚构证件、不可核实图表数值。不要用含糊照片暗示医学、保险或法律结论。

## 图片成品检查
- 保存实际图片路径、对应段落、比例和提示词；看过图片再交付。
- 封面主体与正文有关，裁切后仍完整；不强求模型直接画复杂中文标题。
- 同篇色调和风格一致，正文配图有解释作用，不反复复制封面。
- 新闻采用明确的示意图，不冒充真实报道现场；需要真实照片时必须有来源与使用权。
