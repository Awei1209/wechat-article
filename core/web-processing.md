## 操作
1. 初稿先具备来源依据，保存原始版本。只提交本次拟发布正文；不把内部账号资料、后台数据、凭据或审稿备注混入文本。需要额外敏感材料时另行确认。
2. 在已登录的舟吾净文页面确认模式、额度和实际消费提示。有用户明确授权的额度时按范围执行；没有预算或需要充值、订阅时先说明实际费用再取得授权，不自行购买。保留原文和引用；网页结果只作为改写候选，不能当作事实来源。
3. 保存网页原始输出。政策条款、直接引语、数字、专名和限定条件逐项对照，记录任何丢失或改义。
4. 将这份处理稿送入腾讯朱雀官方文本检测。记录提交版本、时间、字数、页面原始结论和原样数值（页面没有就不补写），保存可用报告或截图引用。遇登录、验证码、空白页、额度或长度限制，记录真实阻碍并交接必要步骤，不写成“检测通过”。
5. 核对来源与原稿，修改不准确、拗口、夸大或不符合账号受众的表达。不为降低数值添加错别字、虚构亲历、伪造引用或改错事实。检测结果不证明原创、事实正确或符合发布要求；不设未经用户确认的“合格率”，也不保证某个数值。
6. 若检测后修改正文，保留修改记录；原结果仅适用于原输入，当前稿标待重新检测。重新检测后复核，如未再修改正文即可进入排版。避免只为追求数值无限循环付费。
7. 文章与贴图分别检查排版、图片、来源、手机可读性；贴图检测对象为逐页文字，不把它当作图片检测。短文或标题不满足网站长度要求时如实记录，不填充无关文字凑字数。
8. 页面无法由助手操作时，可由用户完成同一步并返回对应版本的结果；标注“用户操作/用户提供”，助手继续事实复核。没有证据的阶段保持未完成。

## 文件与版本
每组选题在同一个目录保存：
- article.md、image-post.md：当前工作稿，带准确阶段。
- sources.md：事实依据。
- processing-log.md：下面的日志。
- versions/article-v01-original.md：初稿。
- versions/article-v02-web.md：网页原始输出。
- versions/article-v03-reviewed.md：事实与语气复核稿；有后续修改继续递增版本。
- 贴图相应使用 image-post-v01-original.md 等文件名。
- reports/：有实际产出才保存检测报告或截图；避免把个人信息提交到公开仓库。
