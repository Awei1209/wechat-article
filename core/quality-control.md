# 成品质量检查

直接完成成品并交付用户手动修改；不把第三方降重、改写或AI检测作为制作环节。

- 事实：核查人名、地名、日期、数值、单位、分母及来源；区分事实、观点和推断。
- 条件：政策地区、适用对象、有效时间与例外不能被简化掉；重点检查否定词。
- 表达：标题与正文一致，语句自然，去除空话、病句、夸张与虚构亲历。
- 定位：符合账号读者；日本号面向中国，03讲钱和政策、07讲人和生活。
- 双格式：文章与贴图事实一致；贴图有实际成图与配文，不以脚本代替图片。
- 版面：检查手机字号、对比、裁切、图片顺序、来源可读性与本地链接。
- 交付：正文、预览、图片、下载包和修改入口齐全；标明未发布，交由用户修改与决定发布。

历史网页处理和检测资料只作追溯，不作为未来默认流程。
