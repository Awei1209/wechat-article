# 网页改写后的质量复核

网页输出是待校对稿。先检查事实与语义，再检查读者体验，最后让检测记录对应发布正文版本。

- 否定词：不免费/不收费、不能/可以、未必/一定，逐项对照原稿。
- 数字：年份、比例、金额、年龄、人数及分母完整保留。
- 政策：机构名称、适用地区、条件、政策日期和特殊情况不得泛化。
- 语句：修复引号、残句、错别字和不自然的同义替换；不为降低检测分数保留病句。
- 来源：保留引用标记及可查链接，不让网页改写伪造来源或采访。
- 版本：原稿、网页输出、校对稿、终稿分别保存。检测只对实际提交的版本负责。
- 格式：贴图不检测；文章用同一终稿进行检测和排版，排版只改变样式。

2026-09-26实测：网页曾将“中秋不免费”改成“不收费”、将“我还不是为你好”改成“我不是为了你好”。因此不可自动把改写结果当成发布稿。
