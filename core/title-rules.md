# 共用标题规则
先写清读者是谁、遇到什么事、能获得什么信息，再决定标题。每题给3个备选：直接说明型、具体场景型、疑问解释型，并推荐1个。

- 标题必须由正文与已核实来源支撑；数字清单与正文数量一致。
- 可以有冲突与反常识，但不虚构结论，不用“所有人”“绝不”“稳赚”“百分百”等无法证明的断言。
- 新闻写清时间、地点、主体；单一个案不能代表日本全社会、所有宝妈或所有老人。
- 政策标题保留地区、对象和条件；不能把征求意见、地方试点写成全国已实施。
- 不伪造亲历、专家背书、收入截图或人物对白，不用羞辱群体、制造对立换点击。
- 历史爆款标题按原文存档，不意味着沿用其绝对化措辞。

## 账号切入方式
| 账号 | 可用结构（不是事实结论） |
| --- | --- |
| 01 | 一个日常场景＋普通人的实际难处＋可讨论的问题 |
| 02 | 具体任务＋工具/方法＋真实测试结果，写明成本与限制 |
| 03 | 地区/人群＋政策事项＋条件/办理要点 |
| 04 | 带娃场景＋容易忽略的细节＋可操作清单 |
| 05 | 车主场景＋常见误区＋规则解释，避免固定险种万能答案 |
| 06 | 日本具体事件＋已证实变化＋对相关人群的影响 |
| 07 | 人生阶段＋具体关系＋有边界的生活建议 |

文章标题可强调解释；贴图封面只保留一个重点，但不得删掉关键条件。提交前逐项检查：正文兑现、事实核查、适用范围、无假紧迫、无未经证实的标签。
